# Rock Paper Scissors

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. The player competes against the computer, with the game generating random computer choices and displaying the result.

## 🎮 Features

* Player vs. Computer gameplay
* Random computer choice
* Interactive buttons for Rock, Paper, and Scissors
* Displays game results dynamically
* Score tracking
* Simple and responsive user interface

## 🛠️ Technologies Used

* HTML5 – Structure
* CSS3 – Styling and layout
* JavaScript – Game logic and interactivity

## 📂 Project Structure

```text
Rock-Paper-Scissors/
├── index.html
├── style.css
└── script.js
```

## 🎯 Purpose

This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and basic web development.
